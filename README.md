# Arbeecle — indirmeler

Bu repo yalnızca **Arbeecle** uygulamasının indirilebilir sürümlerini barındırır.
Kaynak kod ayrı (private) bir repodadır.

En son sürümü **[Releases](../../releases/latest)** sayfasından indirin:

- **Arbeecle-macOS.zip** — macOS (.app, çift tıkla çalışır, Python gerekmez)
- **Arbeecle-Windows.zip** — Windows (.exe)
- **Arbeecle-lite.zip** — hafif sürüm (Python kurulu ileri kullanıcılar için)

İmzasız olduğundan ilk açılışta macOS "tanımlanamayan geliştirici" / Windows
SmartScreen uyarısı verebilir (macOS: sağ tık → Aç). İlk açılışta çeviri ve ses
modelleri bir kez iner; sonrası çevrimdışı çalışır.
